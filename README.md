# 🧠 NeuraBlog — Full Stack MERN Blogging Platform

NeuraBlog is a production-ready full stack blogging platform built using the MERN stack. It allows admins to create and manage blogs, while users can browse, read, and comment on posts. The project demonstrates real-world full stack development, authentication, REST APIs, and deployment.

---

## 🚀 Live Demo

Frontend: https://neura-blog-mu.vercel.app  
Backend: https://neura-blog-server-pi.vercel.app  

Admin Panel: `/admin`

---

## ✨ Features

### User
- Browse and read blogs
- Search and filter blogs
- Responsive design
- Comment on blog posts

### Admin
- Secure JWT authentication
- Create, edit, delete blogs
- Upload and manage images
- Publish / unpublish blogs
- Manage comments via dashboard

---

## 🛠️ Tech Stack

**Frontend**
- React, Vite, Tailwind CSS
- React Router, Axios

**Backend**
- Node.js, Express.js
- MongoDB, Mongoose
- JWT Authentication
- Multer, ImageKit
- CORS

**Deployment**
- Frontend: Vercel
- Backend: Vercel
- Database: MongoDB Atlas
