# 🧠 NeuraBlog — Full Stack MERN Blogging Platform

NeuraBlog is a production-ready full stack blogging platform built using the MERN stack. It allows admins to create, manage, and publish blogs, while users can browse and read posts through a modern responsive interface.

## ✨ Features

- Secure admin authentication using JWT  
- Create, edit, delete, and publish blogs  
- Image upload and optimization with ImageKit  
- RESTful API built with Node.js and Express  
- MongoDB Atlas cloud database integration  
- Fully responsive UI built with React and Tailwind CSS  
- Production deployment with frontend and backend hosted on Vercel
